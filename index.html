이전에 연결한 폴더에 다시 접근할까요?

브라우저 보안 정책상 폴더 접근 권한은 매 세션마다 다시 확인해야 합니다.
아래 버튼을 누르면 파일을 다시 찾을 필요 없이 바로 이어집니다.

인사관리대장이 들어있는 폴더를 연결해주세요

★인사관리대장로 시작하는 xlsx 워크북이 들어있는 폴더를 선택하면, 그 안에서 가장 최근에 수정된 파일을 자동으로 찾아 읽습니다.
매달 파일명이 바뀌어도(예: ★인사관리대장_260901 → ★인사관리대장_261001) 다시 선택할 필요 없이 [새로고침]만 누르면 최신 파일을 자동으로 다시 찾습니다.

크롬 또는 엣지에서 «폴더 선택» 버튼이 폴더 선택 창을 띄우고, 이후 새로고침 시 그 폴더 안에서 «★인사관리대장»으로 시작하는 xlsx 중 최신 파일을 자동으로 다시 찾습니다. 이 방식(File System Access API)은 크로미움 계열 브라우저(Chrome·Edge)에서만 지원되며 사파리에서는 지원되지 않습니다. 지원되지 않는 환경에서는 새로고침 시마다 폴더를 다시 선택하는 방식으로 자동 전환됩니다.
